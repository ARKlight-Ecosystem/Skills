# ARKlight component vocabulary (v0.70 / main branch)

Pulled directly from `arklight/ir/schema.py` (the closed node registry)
and `arklight/api.py` (reactive/interactive functions + classes).
Everything here is what's actually checked and shipped — not every
component is documented elsewhere, so this list is the ground truth.

## Structural / HTML-tag components (import-free, from stdlib preamble)

All text-and-container tags ARKlight recognizes by name. `Page` is
required as the root of every route's return value.

```
Page, Container, Heading, Text, Button, Link, Image, List, Item,
Header, Footer, Main, Nav, Section, Article, Aside, Figure,
FigCaption, Details, Summary, Strong, Em, Small, Mark, Code, Cite,
Abbr, Sub, Sup, Span, Time, HorizontalRule, LineBreak, Pre,
Blockquote, Form, Input, Textarea, Select, Option, OptGroup, Label,
FieldSet, Legend, Table, TableHead, TableBody, TableFoot, TableRow,
TableHeaderCell, TableCell, Caption, Video, Audio, Source,
OrderedList, DescriptionList, DescriptionTerm, DescriptionDetails,
Picture, PictureSource, Progress, Meter, Datalist, Output, Dialog,
Kbd, Samp, Var, Data, Ins, Del, Q, Dfn, Address, Wbr, Bdi, Bdo, Ruby,
Rt, Rp, ColGroup, Col, Track, Map, Area, IFrame, NoScript
```

Most take `text_only_children=True` (their children must be plain
text/strings, not nested components) or `allow_children=False`
(self-closing, like `Image`/`Input`) — check `schema.py` directly if
a build fails with a children-shape validation error.

## Reactive / interactive (from `arklight/api.py`)

| Name | Signature (key args) | What it does |
|---|---|---|
| `State(name, initial, ...)` | `persist`, `media`, `query`, `history` | Declare page-scoped reactive state |
| `Bind(name)` | | Reference a `State(...)` value where a literal would go |
| `Computed(name, deps=(...), derive=...)` | | Declare a derived value |
| `Derive` | class, closed set of derivation ops | e.g. `Derive.multiply(...)`, used as `Computed(..., derive=...)` |
| `Action` | class, closed set of state-mutating ops | e.g. `Action.increment("count")`, used as `on_click=...` |
| `Watch(name, then=...)` | | Side effect when a state value changes |
| `Repeat(name, template=...)` | with `RepeatItem` | Per-item list rendering |
| `Show(predicate, *children)` | with `Predicate` class | Conditional rendering |
| `Predicate` | class, closed set of conditions | Used as `Show(...)`'s first arg |
| `PlatformAPI` | class, v0.065+ | Closed vocabulary of platform capabilities (db, etc.) |
| `Provider` | class, EXPERIMENTAL | External-service declaration — see `docs/Foundational/PROVIDER-SDK.md` in the main repo |
| `component(...)` | decorator | Register a render function as a reusable named component |
| `Site(...)` | class | The application object — `site = Site(...)`; also owns `site.style(...)` / `site.style_selector(...)` for CSS |

All of `Action.*` / `Derive.*` / `Predicate.*` are **closed,
described vocabularies** — there is no arbitrary-expression form.
When nothing here covers what you need, see "When the closed
vocabulary isn't enough" in `SKILL.md`.
